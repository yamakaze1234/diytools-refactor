# DIY Tools 0.2.8

- 修复旧版 workspace.sqlite 超过 512 MB 时无法迁移的问题：Windows 上已关闭的大型旧库按页只读读取，保留配置和同步基线，不修改旧 data。
- 首次云端接入直接下载当前快照，再接收新增变化。已下载部分数据且没有本机待处理修改的首次接入也可安全续接，不必删除 data。
- 同步显示页数、已接收数量和本地保存阶段，正常进度不再显示为红色错误。
- 首次使用页、更多菜单和数据与同步窗口增加“导出诊断日志”，忙碌或报错时也能导出。日志仅含本次运行的版本、阶段、错误类别和耗时，不含账号凭据、配置明细或原始错误内容。
- 延续 0.2.7 的普通编辑和批量修改误冲突修复。

更新保留本机数据。旧版迁移前请正常退出旧程序；大型旧库仍有未合并日志时，先正常打开并退出旧版再迁移。原有缺失图片会显示数量。
遇到异常，请在关闭程序前导出诊断日志。此日志用于定位问题，不代表首次同步已经成功。网络和图片下载仍受实际环境影响。
