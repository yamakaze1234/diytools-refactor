# 含税成本来源与独立接口

工作台“ERP 同步”在同一窗口显示两个区域：上方 ERP 库存同步（同时更新 ERP 成本），下方核算成本更新（本地 NAS 表格或云端成本）。两区分别在原位置预览和确认，连接信息已保存时默认收起；读取或应用期间互斥，避免交叉操作。

## 本地 NAS

点击“选择 Excel 文件”选取本地或 NAS 文件，自动记录绝对路径，再填写工作表及两列字母，支持 `.xlsb` 和 `.xlsx`。表头必须分别为 `goods_id`、`含税成本`；表头需在前 30 行。列字母默认 BB 与 BO，支持 A 至 XFD，按实际文件调整；已有数字列设置会自动显示为字母。超长商品 ID 应在 Excel 中保存为文本。

仅读取文件中已保存的值，不运行宏、不刷新连接、不保存源文件。无有效成本缓存的行跳过并显示提示；同一 ID 的冲突价格、非法 ID、越界金额及读取途中源文件变化都会中止本批读取。源文件或目录不可访问时，原成本保留。

## 云端成本

原生客户端通过 `costs.page` 调用 PostgreSQL RPC `public.wa_cost_prices(request jsonb)`，每页最多 1,000 条，只返回 `goods_id`、`tax`（元）。不读取历史日志或图片。成员身份确定工作区，客户端不能指定工作区。

首批返回版本摘要 `checkpoint`，后续页带上摘要与 `nextCursor`。目录变更返回 `COSTS_CHANGED`，本批不得部分应用。最多读取 100 页、限时 90 秒；网络请求另受传输层超时约束。完整读取后原生端生成预览，页面只接收摘要和最多 80 处差异。

迁移文件：`cloudbase/migrations/20261023093000_cost_prices.sql`。部署须遵循项目授权与现有迁移流程；其他环境需先拉取原有迁移历史再检查待执行项。

## 本机应用与隔离

保存来源后，普通云同步不再上传或覆盖本机公共成本。NAS 路径与来源仅存本机。配置和模板中的公共成本缓存及独立改价的基准成本不上传；独立改价本身仍属于配置业务数据。

两种来源共用“读取预览 → 确认应用”。应用更新本机所有店铺中匹配 goods_id 的成本，保留 ERP 成本、库存、售价和有效的独立改价；未提供的旧 ID 不清空。预览有效期 10 分钟，期间配置或来源变化必须重新读取。应用前在当前 data 的 `cost-backups` 保存状态备份，数据库事务写入历史和幂等回执；重复确认不会重复应用。

NAS Excel 读取器随主 EXE 内置并按内容摘要准备到 data/runtime，不依赖原有 ERP worker 版本；旧 ERP 辅助程序保持原样。读取器仅包含公开的 Python、pyxlsb、openpyxl 依赖，不包含 ERP 适配器、连接配置或凭据。

## 读取性能

来源设置相同时不写入历史、不重写配置；改变设置只更新根元数据并保留逆向历史。差异预览逐套扫描配置，保留独立改价等原有规则，不构造完整修改后副本。常驻读取器最多缓存最近一份已验证的两列结果，以文件 SHA-256、工作表和列匹配，文件改变即重新解析；缓存命中仍核对读取期间文件未变。

## 连续表格中的显示

库存对应实际配件，未取得快照时显示未知；缺货和偏低分别提示。ERP 成本与含税核算成本分列，含税单价显示整数但底层保留原精度。分期利润在原利润旁以括号显示，便于核对手续费影响。
