# DIY Tools Windows 工作台

完整解压便携包，在可写目录启动 `DIYTools.exe`。首次运行会在旁边建立 `data`，没有连接配置时使用本地模式。配置、配件税价、素材、历史和草稿均保存在本机，不包含在发行包中。

打开“更多 → 检查更新”，有新版时点击“一键更新”。程序下载并核验签名和摘要，保存当前工作台，再退出、替换程序并重启。保存失败会停止安装，输入仍然保留。更新只替换程序，保留 `data` 及本机集成配置；旧程序保留用于回退。

仓库暂为私有时，需要有权访问该仓库的 GitHub 身份。已安装并登录 GitHub CLI 的电脑可复用本机授权；也可在更新窗口的授权设置中保存仅具有此仓库 Contents 读取权限的令牌。令牌保存在 Windows 凭据管理器，不进入业务同步和发行包。仓库公开后无需此授权。

从指向旧更新源的 0.1.0 测试版首次切换时，需正常退出旧程序，将新版 EXE 放回原安装目录，沿用原 EXE 文件名，保留原 `data` 和 `diytools-portable.json`。旧的内置连接、配件目录和可选 ERP 运行时需先由管理员迁移为本机文件；之后的更新直接在软件内完成。不要用空的新 `data` 覆盖原数据。

可选外部集成由管理员在本机配置，详见仓库的配置说明。无集成配置也能编辑、保存和导出本机配置。发行程序不携带真实服务地址、环境标识、账号、密码、私有 ERP 依赖或业务数据。
