# 使用说明

## 首次使用

在仓库首页下载 **Windows 首次使用包**，完整解压到可写目录，运行 `DIYTools.exe`。程序需要 Windows x64 和 Microsoft Edge WebView2 Runtime。包内无需配置开发环境。

程序旁的 `diytools-portable.json` 用于启用便携模式，请保留。首次运行会创建 `data`，用于保存配置、素材、历史和草稿。

未配置团队服务时直接使用本机工作台。需要团队同步或 ERP 时，由管理员按仓库中的 `docs/PUBLIC-INTEGRATIONS.md` 准备本机接入；使用自己的成员账号登录。发行包不附带团队账号、连接配置或私有 ERP 组件。

首次登录空工作台可选择：

- **从云端下载全部数据**：适合新电脑。等待首次同步完成，再开始编辑。
- **选择旧版 data 目录迁移**：先保存并正常退出旧程序，选择同一账号和工作区的旧目录。新版读取资料并写入独立数据库，旧目录保留；个人登录和 SQL 凭据需重新设置。

## 保留登录信息

登录页默认勾选“保留登录信息”。更新后先成功登录一次，后续重开会自动续期并核验成员，无需重复输入账号和密码。续期信息由当前Windows用户的系统凭据管理器加密保留，密码不保存；主动退出或不勾选后的成功登录会清除保留信息。换电脑或移动数据目录需重新登录。

## 日常编辑与批量操作

选择店铺、商品链接和配置，在连续表格中直接搜索配件，修改数量、到手价、独立核算价、展示名称和加购描述。确认状态变为已保存后再退出。ERP 成本和库存通过工作台 ERP 同步读取预览，再确认应用。

点击配件行名后可用 Shift 连选、Ctrl 多选，Ctrl+C 复制，再点击目标行名 Ctrl+V 按位置粘贴。底部“＋ 新增配件”添加配件6、7、8及更多行；新增行可删除，固定栏位可清空，均可撤销。删除不改变其他行编号，配置名称也不会自动重新编号。需要统一配置序号时使用“一键重新编号”，先预览再应用。

实际配件库存区分正常、偏低、缺货、未知与不核算。含税单价在表中以整数显示，计算保留原精度。ERP 和核算利润分别展示，分期后的实际利润在括号中列出。

全店批量修改配件、加购说明或展示名称时，先搜索配件、选择链接和查看配置，再预览并应用。保存成功后弹窗保持打开，可继续操作或单次还原最近一批修改。还原只恢复本批修改的字段；后续对同字段的修改会受到保护。

输出源差异可按配件分类查看，同一字段和相同前后内容的变动成组展示；可以整组选取或逐项选择，再应用选中的差异。更新后可选择所选链接全部配置图或仅本次变动配置图，图片生成后选择保存目录。当前窗口可还原最近一次修改一次；取消导出不影响还原，已导出的图片保留。

连续表格采用固定槽位；如需按原明细调整排序，可进入“完整编辑”的展示明细，使用六点手柄或上下方向键。导入价格后，价格提示只在本次导入完成时尝试一次，使用其他功能时不再延迟补弹；可从“工具与资料 → 检查价格变化”主动查看。

## 界面与自由编辑

顶栏切换浅色/深色界面，只影响软件显示，不改变配置图片主题。展开预览进入自由编辑：左侧画布和排版工具、右侧图片设置和对象属性，底部导出。文字可编辑，位置可拖动或用方向键微调，支持撤销重做。“放大内容”和“完整画布”只影响预览，不改变导出尺寸。

界面例图见项目首页及仓库 docs/UI-GUIDE.md。

## 图片与 WPS

批量导出可选择所选链接的全部配置，或仅本次变动配置。每套图保留自己的深浅主题及版式；按链接创建配置图与 SKU 图子目录，文件名使用 `1_配置1.png` 等原序号。

图片任务面板可查看进度、取消、继续未完成项和重试失败项。取消目录选择不算导出成功。导出失败后可重试，不需要重复修改配置；清空任务记录不会删除已经保存的图片，运行中的任务会保留。

导出回 WPS 时，勾选配置并指定起始行，复制数量、配件展示名称、到手价到 F:H。使用纯文本粘贴可保留原模板格式。

编辑器可保存配件8及更多行；ERP 固定导出格式仍最多到配件7，超出时明确提示，不会静默丢弃。

## 保存、同步与备份

本机保存与团队同步分别显示状态。连接团队服务后，登录时启动同步，之后每 2 小时自动同步，也可在“数据与同步”立即同步。可以选择需要同步的店铺；未选店铺不会推进下载游标，重新选中后继续下载。

遇到保存冲突时保留输入，先下载草稿或比较版本，再按提示处理。不要用重复点击保存或强制结束程序代替冲突处理。

正常退出程序后备份整个便携目录，至少保留完整 `data`。换电脑时需要重新设置本机加密凭据。缓存清理只用于回收空间，不能代替数据备份。

## 更新

打开“更多 → 检查更新”，按提示更新。程序核验签名和文件摘要，保存成功后退出、替换程序并重启；保存失败会停止安装并保留输入。Gitea 为主源，GitHub 为备用源。

手动升级时先保存并正常退出，再用新版 EXE 替换原程序，沿用原文件名并保留 `data`、`diytools-portable.json` 及本机接入文件。不要把新空数据目录覆盖到旧目录。

数据库格式升级会保留迁移前备份。需要回退时同时使用匹配的程序与数据库备份，不能仅更换旧 EXE；更新恢复提示中的备份目录应保留。

“更多”仅保留更新和诊断入口。迁移仍在首次接入流程中提供，ERP 仍从工作台 ERP 同步入口使用。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 首次打开提示缺少 WebView2 | 安装 Microsoft Edge WebView2 Runtime 后重试 |
| 保存提示版本变化 | 保留草稿，比较版本；根据实际差异处理 |
| 登录或同步失败 | 检查网络、成员权限和本机接入配置 |
| ERP 不可用 | 请管理员检查可选运行时及适配器；本机编辑和出图仍可使用 |
| 图片导出失败 | 检查素材、目录写入权限和磁盘空间，再重试失败项 |
| 更新失败 | 查看更新提示；也可从仓库首页重新下载并按手动升级步骤处理 |

## 价格保存与本机维护

更新到手价遇到版本冲突时，自动合并本次修改的价格和导入时间，并保留其他字段的独立修改；其他重叠修改仍需确认。连续冲突最多自动重试一次。

更新成功后只保留最近一次完整的可回退备份，更早的成功更新目录直接删除。失败或尚未确认的更新保留；文件占用导致未完成的清理会在下次启动重试。“数据与同步 → 清理本机缓存”也可查看和清理历史更新备份，显示数量、占用与完成结果，不删除当前业务数据。

导出诊断日志未弹出目录时，可使用“查看诊断文本”复制诊断信息。保存等待超时表示写入结果尚未确认，当前输入会保留，请勿直接关闭窗口。

## 首次同步与编辑页签

首次同步遇到云端尚未生成快照时，会自动从已有进度下载同步日志。首次下载可能较慢，可查看进度；无需清理本地数据或更换账号。若云端明确要求检查点但检查点不可用，程序仍停止并保留本机修改。

价格变化弹窗内部的切换和筛选不再影响主编辑页签，关闭弹窗后可正常切换实际配置、升级与加购、图片样式和成本核算。

## 使用 AI 与 CLI

工作台首次启动会在程序旁准备 `diytools-agent.exe` 和 `agent-connection.json`。让能执行本机命令的 AI 访问安装目录，先读取连接文件并执行 doctor，再按自然语言任务查询、预览修改、导出图片与报告，或显式同步。

无需开发环境和专用终端启动脚本。操作时保持工作台运行并先保存人工编辑；AI 查询只读取已保存快照。本机保存、导出、云同步分别返回结果，任务必须等待终态确认。

首次升级后如连接失败，先正常退出再重新打开工作台，并按提示检查诊断信息。请勿让 AI 通过 SQL 直接修改工作台数据库。完整命令和示例见仓库 `docs/AGENT-TOOLS.md`。
