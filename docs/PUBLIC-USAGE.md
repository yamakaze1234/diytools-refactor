# 使用说明

## 首次连接

解压 Windows 使用包到独立目录，运行 `DIY配置工作台.exe`。无需 CMD，也无需安装开发环境。需要 WebView2 Runtime。

首次连接所需的 NAS 地址与 CA 由管理员提供。登录和保存共用这个 NAS 地址，使用者无需提供账号接入文件。

连接页填写名称与正式服务端 HTTPS 地址。自建 CA 的部署勾选“使用自定义 CA”并选择证书；标准 HTTPS 信任不需要导入 CA。测试连接只访问匿名健康接口，核对 TLS 和部署标识；不发送账号密码。通过后保存并重启，进入登录页。

使用原有成员账号登录，可显示/隐藏密码及选择保留登录信息。保留的是系统凭据管理器保护的会话，不是连接 JSON 中的明文密码。首次换目录或换电脑需要重新登录。

## 日常操作

升级后首次进入对应账号和店铺时，工作台会将原有本机配置草稿迁入 IndexedDB，写入成功后清理旧存储。

配置从服务端载入。编辑形成当前连接下的本机草稿，明确保存后才提交服务端；不要把存在本机草稿理解为其他电脑已经收到修改。关联来源或成本版本更新时，保存会自动读取最新依赖并重试。同一套配置被他人保存时仍会保留草稿；“处理冲突”按配件和字段展示开始编辑时、本机草稿、服务器最新值，包含名称、商品 ID、数量、来源、售价和加购变化，并区分本机修改、服务器修改及双方冲突。请求结果未知时查原操作回执，避免重复提交。

“价格”查看全店价格利润，“库存 → 检查价格变化”查看变动。预览只用于编辑，导出时生成高清图片并保存到用户选定目录。

价格表默认沿用左侧配置清单顺序。按链接视图只调整链接内的排序，平铺视图可跨链接排序。依次点击数值列标题可切换升序、降序和默认顺序。达到 100 套时首屏仅展开当前链接，可在工具栏统一展开或收起。价格利润按店铺或链接规则计算，修改后从顶部保存到服务端。

“批量按利润定价”先载入当前链接及勾选配置关联的链接。选择“本店全部链接”后分批载入，并显示进度。输入目标利润后可翻页查看试算结果。

配置图底部“加购与选配”使用加购选配页签的链接加购包与独立文案。配件升级文案显示在对应配件行下方。

“复制配置 → 配件 → 配件公式设置”可从维护表粘贴一条展开公式，应用到本店全部配件或指定配件。设置按店铺和维护表布局保存在本机，可恢复默认。

“维护 → 当前店铺核算价”打开时读取已配置主机成本表的最新保存值。保存 Excel 文件后，可以在工作台点“重新读取成本表”。任一店运营使用“ERP 同步”确认后可更新三店的 ERP 成本、库存和含税核算价。通过“当前店铺核算价”、“输出源维护”或总表“应用到全局核算价”手动修改的核算价等效按手动核算价保存，同步成本表时会保留并在预览中列出；如需重新跟随成本表，可在当前店铺核算价点“重新同步核算价”、在输出源维护恢复共用，或在总表点“全局恢复”。

在总表搜索实际配件时，先显示现有输出源，再补充 ERP 可售候选。选中新品会在当前店铺建源。已有共用维护资料会自动继承，本店核算价可从配件行的“修改输出源”维护。

“维护 → 输出源维护”打开全屏工作表。默认的“共用精简”视图可直接填写共用名称和核算价；切换“三店并排”可核对单店独享值。核算价对比可筛出高于或低于 ERP 的配件。填写共用价后仍会保留单店独享价，核对后点“全部恢复共用”，再点“保存全部更改”。

价格与利润页可导出全店抖店改价模板。导出前可核对有效配置数及跳过明细，在桌面端选择 Excel 保存目录。侧栏链接可拖动排序或移入草稿区，“创建副本”会清空副本的 SPU、SKU 和商品网址。

总表中配件数量大于 1 时，ERP 和含税两列显示对齐的小计和“单价 × 数量”。手动修改含税单价后，可在同一格使用“全局”或“恢复”。

在左栏“主机模板”中可编辑模板、勾选配置并生成当前店铺的草稿链接。只有规格、尚未绑定货号的显卡会提示“待选货号”，生成时可选择具体配件。

## 连接和更新

“更多 → 连接设置”以及登录页均可修改连接。修改后测试、保存并重启，原连接草稿保留。未完成保存、导出或回执确认会阻止切换。

新版使用独立更新通道。启动检查发现新版本后，会居中显示版本和更新说明。点击“稍后再说”或按 Esc 时，本次会话仍可从“更多 → 检查更新”手动打开。升级只替换 EXE，保留 `data` 和 `workbench-connection.json`。第一次切换到服务端数据库版本需下载 Windows 使用包并解压到独立目录。

请勿把整个 data 目录发给他人；它可能包含草稿、登录缓存和本机集成凭据。公开 CA 可由管理员在内部发放，私钥不可随包发放。
