# 使用说明

## 首次连接

解压 Windows 使用包到独立目录，运行 `DIY配置工作台.exe`。无需 CMD，也无需安装开发环境。需要 WebView2 Runtime。

管理员可在构建时内置默认账号认证接入，使用者无需提供 integrations.json；未内置默认值的通用构建仍由管理员配置。外部 data/integrations.json 优先覆盖默认值，格式错误不会静默回退。首次连接所需的 NAS 地址与 CA 由管理员提供。默认认证仅含服务地址和环境标识，不含账号、密码、令牌或数据库密码。

连接页填写名称与正式服务端 HTTPS 地址。自建 CA 的部署勾选“使用自定义 CA”并选择证书；标准 HTTPS 信任不需要导入 CA。测试连接只访问匿名健康接口，核对 TLS 和部署标识；不发送账号密码。通过后保存并重启，进入登录页。

使用原有成员账号登录，可显示/隐藏密码及选择保留登录信息。保留的是系统凭据管理器保护的会话，不是连接 JSON 中的明文密码。首次换目录或换电脑需要重新登录。

## 日常操作

配置从服务端载入。编辑形成当前连接下的本机草稿，明确保存后才提交服务端；不要把存在本机草稿理解为其他电脑已经收到修改。冲突时比较服务端版本与本机编辑；请求结果未知时查原操作回执，避免重复提交。

“价格”查看全店价格利润，“库存 → 检查价格变化”查看变动。预览只用于编辑，导出时生成高清图片并保存到用户选定目录。

## 连接和更新

“更多 → 连接设置”以及登录页均可修改连接。修改后测试、保存并重启，原连接草稿保留。未完成保存、导出或回执确认会阻止切换。

新版使用独立更新通道。“更多 → 检查更新”升级时只替换 EXE，保留 `data` 和 `workbench-connection.json`。旧版不再更新，第一次切换需手动下载使用包，不直接复用旧本地数据库。已有新版测试目录可正常退出后手动替换同名 EXE，保留其余文件。

请勿把整个 data 目录发给他人；它可能包含草稿、登录缓存和本机集成凭据。公开 CA 可由管理员在内部发放，私钥不可随包发放。
